MantisCam

Handheld viewer + camera fleet — flash, configure, go

Chrome / Edge · USB cable · 5 minutes

What you’re setting up

MantisCam is a small system with two parts:

  • The handheld (M5Stack Core2) — a touchscreen gadget that shows the live camera view, saves photos/video/audio, and switches between cameras.
  • The camera (ESP32-CAM) — a tiny board with a lens. It creates its own Wi‑Fi hotspot; the handheld joins that hotspot and pulls the video stream.

You don’t need a home router in the middle for the basic setup. Cable in, flash software, power both devices, connect.

New to this? Follow the numbered steps below. Use a computer with a USB port and Google Chrome or Microsoft Edge (Safari and Firefox usually can’t talk to USB devices from a web page).
Already ship firmware? Binaries and manifests are under firmware/. Core2 multi-profile NVS + CAM POST /config for SoftAP identity. Same binaries for every unit; per-device config is runtime.

Before you start

  1. USB data cable — not charge-only. If the computer never offers a serial port, try another cable first.
  2. Browser — Chrome or Edge on Windows, macOS, or Linux.
  3. Drivers (Windows only, if the board isn’t seen) — many boards need a CH340 or CP210x USB-serial driver from the chip maker. macOS/Linux usually just work.
  4. Hold the right board — Core2 is the thick touchscreen brick. ESP32-CAM is the small board with the camera module (often on a base board with a USB plug).

What success looks like

After power-up you should see the MantisCam splash, then either a live view (if a default camera is on) or the Cameras list.

Bottom of the screen: three zones match the capacitive buttons — A previous screen, B select / record, C next screen.

Status chips in the header: LINK (Wi‑Fi to the camera) and DISK (SD card).

2 · Put software on the camera (ESP32-CAM)

Same idea: USB to the computer, install from the browser. Your camera firmware must be published as firmware/esp32cam-fleet.bin for the button below to work. If that file isn’t on this site yet, flash with your usual CAM pipeline (e.g. the Manager app), then come back for configuration.

Default camera Wi‑Fi (SoftAP) after a stock flash is often network name Mantis_1_Hotspot, password mantis33, camera address 192.168.5.1. The handheld is set up to look for that first.

3 · Name each camera (first time)

If you only have one camera, you can skip this. With several cameras, give each its own hotspot name so the handheld can list and switch between them.

Power the camera alone, join its Wi‑Fi from a phone or laptop, then open http://192.168.5.1 or send a config request (form below builds a ready-to-run command).

Config helper

Fill the fields, then click “Copy setup command”. Paste into Terminal (macOS/Linux) or PowerShell/WSL (Windows) while you’re connected to the camera’s hotspot.
Endpoint: POST http://192.168.5.1/config with header X-Admin-Pass. Body: form fields ap_ssid, ap_pass, name, admin, optional st_ssid / st_pass. Stored in NVS — no unique binary per camera.

4 · Use the handheld every day

  1. Power the camera, then the Core2.
  2. Open Cameras — scan if needed, tap a camera to connect.
  3. Stream — live view; B starts/stops video recording to the SD card.
  4. Snapshot — B previews; on-screen Save to SD writes the file.
  5. Audio — record or play clips from the SD card.

MicroSD goes in the Core2 (FAT32). Folders /images, /videos, and /audio are created automatically.

If something doesn’t work

Install button does nothing / no ports listed

  • Wrong cable or USB hub — plug straight into the computer.
  • Windows: install CH340 or CP210x driver, unplug/replug.
  • Close other serial tools (Arduino IDE, serial monitors) that may lock the port.
  • Some CAM boards need a “boot” button held while connecting — check your board’s docs.

Handheld never links to the camera

  • Confirm the camera hotspot appears in the phone’s Wi‑Fi list.
  • Password and SSID must match a profile on the Core2 (Cameras → scan / edit).
  • Stay near the camera; SoftAP range is short.
  • Header shows DOWN until Wi‑Fi associates; LINK when it’s up.
Updates later: download a new .bin from this site and flash again. No OTA path required for this project.
