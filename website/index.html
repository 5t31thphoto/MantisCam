MantisCam

Handheld viewer and camera fleet — set up and install in one step

Chrome or Edge · USB · a few minutes

What this is

MantisCam pairs a touchscreen handheld with one or more small Wi‑Fi cameras. The handheld joins each camera’s own hotspot, shows the live stream, and can save photos, short video, and audio to a microSD card.

Typical kit: an M5Stack Core2 as the handheld, and cameras such as a Seeed Studio XIAO ESP32S3 Sense or a classic ESP32-CAM module.

Before you install

  1. USB cable that carries data — charge-only cables are the usual culprit when no device appears.
  2. Chrome or Edge — the installer on this page uses the browser’s USB serial support.
  3. Windows — if the board never shows up, install the CH340 or CP210x driver that matches your USB chip, then unplug and reconnect.
  4. Close other tools that might hold the serial port (Arduino IDE serial monitor, etc.).

Install on the Core2

  1. Plug the Core2 into the computer.
  2. Click Install on Core2 and choose the serial device when prompted.
  3. Wait for the write to finish. A blank screen during install is normal.

Set up & install a camera

Fill in the settings, plug the camera in, and press Install. The settings are written to the camera at the same time as the firmware and take effect on its first boot. No serial commands, no extra steps. Each board has its own firmware built for its pins: pick your board and that firmware is installed. If the board plugged in is the wrong chip for your pick, the installer refuses.

XIAO ESP32S3 Sense tips

  • Screw on the antenna. The XIAO has no usable on-board antenna; without the little U.FL antenna the hotspot barely reaches across a desk.
  • No serial port showing up? Hold the B (BOOT) button, plug in USB, release, then press Install. Press R (RESET) after the install finishes.
  • See what it’s doing: after installing, choose Logs & Console in the installer dialog. The camera prints its chip, PSRAM, which board profile it found, and its hotspot.
  • If a camera crashes three boots in a row it starts in safe mode: hotspot and web page up, camera off, with the reason on http://192.168.5.1/. Power-cycle or press RESET to retry.
  • If the log says camera init FAILED, reseat the camera ribbon (lift the latch, push the cable fully in, close the latch).

Day to day on the Core2

  1. Power the camera, then the Core2.
  2. Cameras — scan if needed, tap a unit to connect.
  3. Stream — live view; middle button records to the SD card.
  4. Snapshot — capture a preview, then save to SD when you want to keep it.
  5. Audio — record or play clips from the card.

microSD in the Core2, FAT32. Folders for images, videos, and audio are created as needed.

If install or linking fails

No serial port in the browser

  • Try another cable and a direct USB port (skip the hub).
  • Windows: CH340 / CP210x driver, then replug.
  • Some camera boards need a boot button held while connecting — check the board silk or manual.

Core2 won’t link to the camera

  • Confirm the camera hotspot appears on a phone.
  • SSID and password must match a profile on the Core2.
  • Stay close; hotspot range is short.
  • Header shows LINK when Wi‑Fi is up, DOWN when it isn’t.
